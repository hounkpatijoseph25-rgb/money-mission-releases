# Money Mission

Vos dépenses, vos factures et vos objectifs d'épargne, dans votre poche.

**[Télécharger l'application Android](https://github.com/hounkpatijoseph25-rgb/money-mission-releases/releases/latest/download/money-mission.apk)**

- Fonctionne hors ligne
- 9 langues, 16 devises dont le franc CFA
- Aucune connexion bancaire : vos données restent sur votre téléphone

## Installation

1. Téléchargez le fichier avec le lien ci-dessus.
2. Ouvrez-le depuis vos téléchargements.
3. Si Android le demande, autorisez l'installation depuis cette source.

Ce dépôt ne contient que les versions publiées de l'application.
